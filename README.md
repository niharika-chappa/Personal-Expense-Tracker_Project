# Personal Expense Tracker

A Flask-based web application to manage and track personal income and expenses with category-wise organization and dashboard visualization.

## Features

- User Registration and Login system
- Add income and expense transactions
- Category-wise transaction classification
- Automatic balance calculation (Income - Expense)
- Dashboard with total income, expense, and balance summary
- Transaction history display for each user
- Dynamic category selection based on Income/Expense type
- Interactive bar chart for financial overview

## Technologies Used

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript (Chart.js)


## Installation

1. Clone the repository
2. Install dependencies:
pip install flask flask-sqlalchemy flask-login flask-wtf email-validator
3. Run the application:
python app.py
4. Open in browser:
http://127.0.0.1:5000

## Project Structure

- app.py - Main Flask application
- models.py - Database models
- forms.py - Form definitions
- templates/ - HTML templates
- static/css/ - Styling files
